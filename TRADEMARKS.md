# Trademark and branding guidelines

## 1. Source code license vs. brand assets

The source code in this repository is licensed under the Apache License 2.0.
That license **only applies to source code**, and does not grant permission to
use the project name, logo, visual identity, or author identity in a way that
suggests endorsement or an official relationship.

---

## 2. BossPilot brand assets (this derivative project)

`BossPilot` — including the project name, logo, and any visual brand identity
used by this repository — are brand assets of the BossPilot project.
They are **not** licensed under the Apache License 2.0, even if the source
code is.

### Allowed

- Accurately state that your project is **based on** or **derived from** BossPilot.
- Link back to `https://github.com/we-used-to-be/BossPilot` for factual attribution.
- Preserve the attribution text `"BossPilot"` and the source repository URL in
  NOTICE files, documentation, and user interfaces where required by Apache-2.0.

### Not allowed without written permission

- Present a modified build as the **official BossPilot** release.
- Use `BossPilot` (or confusingly similar names, logos, or slogans) as the
  primary name of another product, fork, commercial service, or derivative.
- Imply or suggest that BossPilot maintainers have reviewed, endorsed,
  partnered with, sponsored, or officially support your fork or derivative.
- Reuse the BossPilot logo or brand visuals as the logo of another product.

---

## 3. JobClaw original project brand assets (upstream)

BossPilot is based on JobClaw by Chris. The following brand guidelines apply
to the original JobClaw project and must be respected in any redistribution:

### Allowed

- Accurately state that a project is based on or derived from JobClaw.
- Link to `https://github.com/Chrisbetheking/job-claw`.
- Preserve the attribution `JobClaw by Chris` in notices and documentation.

### Not allowed without written permission

- Present a modified build as the official JobClaw release.
- Use `JobClaw by Chris` as the primary name of an unrelated commercial service.
- Imply that Chris has reviewed, endorsed, partnered with, or supports a fork.
- Reuse the JobClaw logo as the logo of another product.
